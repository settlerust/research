# First games through the research arena

<ResearchCallout title="Four completed games establish a working arena">
All four ten-point games finished without a recorded server timeout. The games
used the existing fast and ETA builders, with a different seat assignment in
each match. Four games are far too few to distinguish these policies reliably.
