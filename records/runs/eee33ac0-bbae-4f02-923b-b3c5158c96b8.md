# Interrupted JSON-input arena competition

Experiment: `981f6ecf-d016-4698-a14e-35bf1ed8876d`

The user requested a complete restart with text inputs and an ASCII board while
the first two games were running. Both game processes received SIGTERM, and the
runner finalized their journals as incomplete. The remaining eight never started.
No winner was recorded and no interrupted game is counted in the replacement.
This was an intentional protocol change, not an outcome-based exclusion.
